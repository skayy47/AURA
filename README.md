## What is AURA?

AURA is a full-stack data platform that takes you from a raw file upload to AI-powered insights. A Next.js 14 frontend talks to a FastAPI backend over a typed REST + SSE contract — upload any structured dataset, auto-clean it, explore interactive charts, ask Claude or GPT about it, and export in any format.

The UI runs on a custom **Luminal Void** design system with an animated aurora backdrop, a pipeline road that visually connects the five stages, squiggly glow cards, neon buttons, and a branded SVG loader.

## Architecture

```
┌──────────────────────────┐      REST + SSE        ┌──────────────────────────┐
│  AURA-FRONTEND (3000)    │ ─────────────────────▶ │  AURA-BACKEND (8000)     │
│  Next.js 14 · React 18   │                        │  FastAPI · Uvicorn       │
│  Tailwind · Zustand      │ ◀───────────────────── │  Pandas · Anthropic SDK  │
│  Framer Motion · Recharts│       JSON / stream    │  OpenAI SDK · Whisper    │
└──────────────────────────┘                        └──────────────────────────┘
```

- Frontend is a pure client — all data, AI, and file processing happen on the backend.
- Sessions are keyed by UUIDs generated by the backend on first upload; the frontend keeps the ID in a Zustand store.
- AI responses stream over SSE (`/api/ask`) for token-by-token rendering.

## Pipeline

| Step | Route | What it does |
|------|-------|--------------|
| 📂 **Ingest** | `/ingest` | CSV · XLSX · JSON · Parquet · TSV — encoding auto-detected, previews first 5 rows |
| 🧼 **Clean** | `/clean` | Configurable pipeline: rename columns, normalize strings, detect dates, drop empty cols, fill missing, drop duplicates — full change log returned |
| 🔍 **Explore** | `/explore` | Profile + missing-value heatmap + correlation matrix |
| 🤖 **AI Chat** | `/ai-chat` | Claude Sonnet 4.6 or GPT-4o-mini with streaming — dataset context injected |
| 📄 **Docs** | `/docs` | Export to CSV · XLSX · JSON · Parquet |

## Quick Start

Requires Python 3.11+ and Node 18+.

**1. Clone and set up environment**
```bash
git clone https://github.com/YOUR_USERNAME/AURA
cd AURA

python -m venv .venv
.venv\Scripts\activate       # Windows
# source .venv/bin/activate   # macOS / Linux

cp AURA-BACKEND/.env.example AURA-BACKEND/.env   # add your API keys
```

**2. Start the backend (terminal 1)**
```bash
cd AURA-BACKEND
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

**3. Start the frontend (terminal 2)**
```bash
cd AURA-FRONTEND
npm install
npm run dev
```

Open **http://localhost:3000** — you'll land on the Ingest page. Upload any CSV to try it.

Backend health: **http://localhost:8000/health** · Interactive API docs: **http://localhost:8000/docs**

## Environment Variables

Backend reads from `AURA-BACKEND/.env`:

| Variable | Required | Description |
|---|---|---|
| `ANTHROPIC_API_KEY` | For Claude | [console.anthropic.com](https://console.anthropic.com/) |
| `OPENAI_API_KEY` | For GPT-4o-mini | [platform.openai.com](https://platform.openai.com/api-keys) |
| `POPPLER_PATH` | For PDF OCR | Path to Poppler `bin/` folder (Windows only) |
| `DEBUG` | No | `1` to enable debug logging |

Frontend reads `NEXT_PUBLIC_API_URL` from `AURA-FRONTEND/.env.local` (defaults to `http://localhost:8000`).

## REST API

| Method | Endpoint | Purpose |
|--------|----------|---------|
| `GET` | `/health` | Liveness probe |
| `POST` | `/api/ingest` | Multipart upload — returns `{session_id, meta, preview}` |
| `POST` | `/api/clean` | Run cleaning pipeline with `CleaningConfig` |
| `GET` | `/api/explore/{session_id}` | Profile + missing-value stats |
| `POST` | `/api/ask` | Ask AI (SSE stream of `{chunk}` events) |
| `GET` | `/api/export/{session_id}/{format}` | Download cleaned dataset |

Full OpenAPI schema: **http://localhost:8000/docs**

## Tech Stack

**Frontend**
- Next.js 14 (App Router) · React 18 · TypeScript 5
- Tailwind CSS 3.4 with custom Luminal Void tokens
- Zustand (state) · Framer Motion (animation) · Recharts (charts)

**Backend**
- FastAPI 0.111 · Uvicorn · Pydantic 2
- Pandas 2.2 · NumPy · OpenPyXL · PyArrow
- Anthropic SDK (Claude Sonnet 4.6) · OpenAI SDK (GPT-4o-mini)
- Tesseract + Poppler (OCR) · OpenAI Whisper · librosa · OpenCV

## Legacy Streamlit App

The original single-process Streamlit implementation (V2.1) is preserved at the repo root (`app.py`, `pages/`, `engines/`, `state/`, `utils/`). It is no longer the recommended way to run AURA — the Next.js + FastAPI split in V3 is the canonical stack. The Streamlit version remains as reference for the Luminal Void design language and the pure-Python engine implementations.

To run the legacy version:
```bash
pip install -r requirements.txt
streamlit run app.py
```
